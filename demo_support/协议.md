# 用量导出流

HTTP 返回 gzip 文件本身，不设置 Content-Encoding。解压后的 UTF-8 NDJSON 依次为一条 header、多条 usage、一条 trailer；明细 count 按中间物理记录计，totals 按 meter 汇总非 cancel 行的原始 quantity，尚未做 quantity_factor 换算。report/correct/cancel 对应既有业务动作，reason 在更正和取消时随行提供；usage_id 不含导出号。映射绑定 contract_id、side 和版本。

/usage 包含两个 gzip member，?cut=1 截断校验尾部，?bad=1 含不可解析数量，?total=1 总量不符。导出号相同而内容不同需作为冲突保留。

运行 python demo_support/source.py --port 8787 可启动回环来源；运行 python demo_support/check.py 检查样本和故障开关。来源仅产生输入，不调用业务导入。
